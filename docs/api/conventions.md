# API Conventions & Protocols: Narrative-Craft

## 1. Protocol Architecture
Narrative-Craft is an asynchronous, headless HTTP/JSON and Server-Sent Events (SSE) service compliant with **OpenAPI 3.1.0**.

- **Base URL**: `http://localhost:8000` (Local) / `https://api.narrative-craft.internal` (Cloud)
- **Data Exchange**: All JSON payloads must use UTF-8 encoding with standard camelCase or snake_case as declared in the schema.
- **Date-Time Format**: ISO 8601 extended format (`YYYY-MM-DDTHH:MM:SS.sssZ`) in UTC.

## 2. Authentication & Authorization
Requests must supply an authorization bearer token:
```http
Authorization: Bearer <JWT_OR_API_TOKEN>
```
The token payload encodes tenant scope:
- `worlds:write`, `worlds:read`: Manage world templates and root settings.
- `turns:write`: Execute narrative actions on timelines.
- `timelines:write`, `timelines:read`: Fork and inspect multiverse branches.
- `graph:read`: Query graph neighborhoods and active node properties.

## 3. Server-Sent Events (SSE) Streaming Format
The turn execution endpoint (`POST /v1/timelines/{id}/turns`) streams real-time tokens and structured graph state deltas over HTTP SSE.

Clients must specify:
```http
Accept: text/event-stream
Cache-Control: no-cache
```

### Event Types Emitted:
1. `event: token`: Chunked literary prose as generated by the LLM.
   ```text
   event: token
   data: {"text": "You carefully step over the debris."}
   ```
2. `event: graph_delta`: Verified property graph mutations in structured JSON.
   ```text
   event: graph_delta
   data: {"mutations": [{"action": "UPDATE_NODE_PROPERTY", "node_id": "loc_crypt", "key": "explored", "value": true}]}
   ```
3. `event: telemetry`: Latency and token consumption metrics.
   ```text
   event: telemetry
   data: {"turn_latency_ms": 1120, "tokens": 420}
   ```
4. `event: complete`: Final turn termination confirmation.
   ```text
   event: complete
   data: {"turn_id": "turn_01HXYZ...", "event_id": "evt_9981...", "status": "COMMITTED"}
   ```

## 4. Standard Error Format (RFC 7807)
All error responses adhere to the RFC 7807 Problem Details standard with `Content-Type: application/problem+json`:

```json
{
  "type": "https://narrative-craft.internal/errors/precondition-violation",
  "title": "Precondition Causality Violation",
  "status": 422,
  "detail": "Character 'char_vespera' attempted to unlock 'gate_iron_portcullis' without possessing required item 'item_silver_key'.",
  "instance": "/v1/timelines/b2c3d4e5-f6a7-8901-bcde-f12345678901/turns",
  "invalid_preconditions": [
    {
      "rule": "PossessesRequiredItemRule",
      "required_item": "item_silver_key",
      "actor": "char_vespera"
    }
  ]
}
```

### Common HTTP Status Codes
- `200 OK`: Successful synchronous retrieval or state query.
- `201 Created`: World, timeline, or branch created.
- `400 Bad Request`: Malformed JSON or schema validation failure.
- `401 Unauthorized`: Missing or expired bearer token.
- `403 Forbidden`: Token lacks required scope for world or timeline.
- `404 Not Found`: World ID or timeline ID does not exist.
- `409 Conflict`: Active timeline session locked by concurrent turn.
- `422 Unprocessable Entity`: Deterministic world causality rule violation.
- `500 Internal Server Error`: Unhandled exception or LLM provider failure.
- `503 Service Unavailable`: Dependent database, cache, or vector store unhealthy.
